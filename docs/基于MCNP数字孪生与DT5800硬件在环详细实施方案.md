# 基于已有 MCNP 建模的核反应堆数字孪生与 DT5800 硬件在环详细实施方案

> **编制说明**：本方案严格针对 `docs/需求.md` 中提出的四项核心需求量身定制，结合现有 `MCNP_input/YBS-0.84329.i` 零功率装置物理建模与前期已完成的 `he3sim` 微观中子探测脉冲仿真内核，对“MCNP加速是否引入机器学习”、“DT5800实时输出支持能力与机制”等关键技术问题给出了明确调研结论，并制定了可直接指导工程编码的落地实施方案。

---

## 一、核心技术问题调研与权威结论解答

### 问题 1 调研：后端使用 MCNP 计算速度较慢，是否需要引入机器学习（ML）来加快？
* **现状痛点**：
  现有 `MCNP_input/YBS-0.84329.i` 模型采用 `KCODE 1e4 1.0 150 1150`（每代 10,000 粒子，跳过 150 代，统计 1000 代活跃代），在多核工作站上执行单次完整的临界与通量计算需要 **30分钟至数小时**；即便大幅缩减粒子数至极限（单次计算几千粒子），耗时仍在 **30秒以上** 且统计涨落方差极大。这与前端 UI 用户“拖动控制棒滑块、插拔组件时获得即时反馈（$<100\text{ ms}$）”的交互需求存在本质冲突。
* **技术路线调研比选**：
  1. **全在线计算（纯 MCNP）**：不可行，计算延迟完全破坏交互体验；
  2. **传统网格高维多项式插值（Lookup Table + Spline）**：对单棒简单运动可行，但一旦涉及“组件插拔（离散组合爆炸）+ 调节棒/安全棒连续高度变化”，多维参数网格节点呈指数级增长，插值表存储与离散维度受限；
  3. **机器学习代理模型（Surrogate Model / 深度学习回归）**：在核工程先进反应堆数字孪生领域（如 IAEA 数字化规范、MIT 研究堆数字孪生平台、清华/西安交大数字反应堆），**“离线精细采样 + 在线轻量代理模型推理”** 是公认的黄金标准。
* **明确结论与推荐方案**：
  **【必须引入轻量级机器学习/代理模型，且采用两阶段混合架构】**：
  - **离线阶段（数据积累）**：编写自动化 Python 脚本参数化驱动 MCNP，自动变动棒位高度（0~100% 行程）及典型组件插拔布局，批量运行提取 $k_{\text{eff}}$、$\beta_{\text{eff}}$、$\Lambda$ 及两个 He-3 虚拟测点（Cell 1501 与 1503）的 F4/F14 中子通量，构建高保真样本集（300 ~ 800 组工况）；
  - **训练阶段（极轻量模型）**：选用 **梯度提升树（XGBoost/LightGBM）** 或 **紧凑型全连接神经网络（MLP，3~4 层）**。此类模型在 CPU 上单次推理耗时 **$< 1\text{ ms}$**，模型体积仅数兆字节，对复杂非线性空间阴影效应具备优异泛化能力；
  - **在线阶段（微秒级交互）**：前端 UI 拖动滑块时，后台直接调用预训练好的轻量模型（导出为 ONNX 或 joblib），实现 **无感知即时刷新物理参数与通量分布**；同时预留“后台异步发起 MCNP 高保真精确校核”的按钮，兼顾即时性与严谨性。

### 问题 2 调研：DT5800 硬件是否支持我们的“实时输出”？机制与限制是什么？
* **DT5800 硬件架构深入分析**：
  CAEN DT5800 拥有 **双通道 14-bit 高速 DAC**，输出速率高达 $1\text{ GS/s}$（或 $250\text{ MS/s}$）。针对“实时输出”，DT5800 硬件具有两种完全不同的工作机制：
  1. **AWG（任意波形发生器）模式机制**：
     - **板载内存深度**：每通道仅 $1\text{ MSamples}$ 内存；
     - **时间窗口**：在 $250\text{ MS/s}$ 采样率下，$1\text{ MSamples}$ 只能容纳 **$4\text{ ms}$ 的物理波形**（若降采样至 $50\text{ MS/s}$，则容纳 $20\text{ ms}$）；
     - **USB 传输瓶颈**：上位机通过 USB 2.0 写入 $1\text{ MSamples}$（约 2 MB）需要约 $60\sim 100\text{ ms}$，而硬件以 $250\text{ MS/s}$ 播放只需 $4\text{ ms}$。**因此，AWG 模式在物理上不支持“由上位机源源不断逐点推流、无限时长的无缝实时流式播放”（必发生内存欠载中断）**。
     - **AWG 的正确使用机制**：**“块循环播放（Looping）+ 工况切换乒乓刷新（Block Swap）”**。在当前工况下，软件生成一段统计平衡的代表性波形块（1 MSamples），写入 DT5800 开启循环播放；当用户改变棒位时，上位机重新生成新工况的波形块并刷写内存更新硬件。
  2. **Emulation（数字探测器仿真）模式机制**：
     - **这是 CAEN 官方专为“无时间限制实时连续输出”设计的模式**；
     - **机制**：脉冲是由 DT5800 板载 FPGA 内部硬件实时合成的，最高输出率达 $10\text{ Mcps}$。上位机只需一次性下发 He-3 能谱直方图与双指数脉冲上升/衰减形状参数，然后在运行期间，上位机通过 USB 以 $20\sim 50\text{ Hz}$ 的频率向寄存器写入当前的到达率 $\lambda(t)$；
     - **优势**：**真正的全实时、无限时长、零延迟输出**，完全没有板载内存耗尽的风险。
* **明确结论与推荐方案**：
  **【严格满足用户 AWG 数据格式要求，同时支持 Emulation 模式的“双轨制”闭环输出方案】**：
  - **第一轨（用户明确要求的 AWG 模式输出）**：定义严格的 DT5800 AWG 数据导出模块。将 `he3sim` 合成的时域脉冲序列量化为 14-bit DAC 整数格式（$\pm 2\text{ V}$ 映射为 $[-8192, +8191]$），以二进制/文本格式导出，支持单次触发瞬态回放与定周期循环回放；
  - **第二轨（用于长时间交互演化的 Emulation 模式）**：预置 He-3 探测器参数，在用户拖动棒位导致通量演变时，流式更新到达率寄存器，实现物理模拟信号连续动态变化。

## 三、各模块详细技术实施方案

### 3.1 模块一实施方案：基于 YBS 模型的堆芯数字孪生与 ML 代理引擎
1. **MCNP 参数化与组件操作接口**：
   - 解析 `YBS-0.84329.i`：组件栅格 `LAT=2 u=1`（$21 \times 21$ 点阵），燃料组件单元充填石墨（`u=60`）、冷却剂（`u=50`）、90%燃料棒（`u=9000`/`9001`）、B4C控制棒（`u=2001`/`7000`）；
   - 编写 `MCNPModelManager`：实现程序化修改指定坐标位置的充填单元编号，完成组件插拔；修改控制棒表面卡高度参数，完成安全棒与调节棒位置调整。
2. **离线高保真样本集构建**：
   - 采样维度：安全棒行程 $z_{\text{safety}} \in [0, 100\%]$、调节棒行程 $z_{\text{reg}} \in [0, 100\%]$、典型组件插拔配置（对称移除/中心替代）；
   - 编写自动化批处理脚本驱动 MCNP，自动抽取输出卡中的 $k_{\text{eff}}$、代时间 $\Lambda$ 以及 `F4:N 1501`、`F14:N 1503` 的通量计数与相对误差，清洗生成规范的结构化数据集 `mcnp_dataset.h5`。
3. **ML 代理模型训练与导出**：
   - 模型选型：采用多输出梯度提升回归树（XGBoost）或 4 层多层感知机（MLP，PyTorch 实现）；
   - 性能指标：要求 $k_{\text{eff}}$ 预测相对误差 $\le 0.05\%$，测点通量预测相对误差 $\le 1.5\%$，推理耗时 $\le 1\text{ ms}$；
   - 导出为 ONNX / Joblib 格式，供前端无缝快速调用。
4. **可视化交互界面（Streamlit）**：
   - 提供堆芯栅格二维交互视图，点击单元格可切换组件类型（燃料棒、铍棒、B4C棒、铝棒）；
   - 提供安全棒脱扣按钮（一键 Scram 落棒，动态曲线回弹）与调节棒高度连续滑块；
   - 仪表盘实时显示当前 $k_{\text{eff}}$、反应性 $\rho$（单位 pcm 或 $\$$）、瞬发衰减常数 $\alpha = (\beta - \rho)/\Lambda$，以及测点通量柱状图。

### 3.2 模块二实施方案：堆芯状态至探测器信号生成内核（复用 `he3sim`）
1. **“开堆/打入外源”状态机逻辑**：
   - 在 UI 上设立核心控制按钮“【打入外源 / 启动系统】”；
   - 未打入外源时，堆芯处于深次临界本底状态，仅输出极低本底泊松噪声；
   - 点击启动后，状态机置为 `RUNNING`，外中子源注入，依据当前反应性激发分支过程链式增殖。
2. **宏观通量向微观事件映射**：
   - 根据测点通量 $\Phi_1, \Phi_2$ 计算 He-3 探测器到达率：$\lambda_k(t) = \epsilon_k \cdot V \cdot \Sigma_a \cdot \Phi_k(t)$；
   - 将当前工况的 $(\lambda_k, \alpha, k_{\text{eff}})$ 动态注入现有 `he3sim.physics.chains.BranchingProcessGenerator`，抽样输出事件时间戳与分支代数。
3. **连续波形渲染与 AWG 格式化**：
   - 沿用 `he3sim.synthesis.renderers`，卷积 He-3 壁效应能量谱与双指数脉冲内核 $A(e^{-t/\tau_d} - e^{-t/\tau_r})$；
   - 叠加高斯白噪声与 $1/f$ 基线漂移，生成浮点电压序列；
   - **格式化为 DT5800 AWG 数据格式**：将物理电压（标称量程 $\pm 2\text{ V}$）线性映射到 14-bit 有符号整数 $[-8192, +8191]$，导出为 DT5800 识别的规范格式（二进制 `.raw` / ASCII `.txt`）。

### 3.3 模块三实施方案：针对硬件 DT5800 输出完成硬件在环闭环
1. **底层通信封装与设备诊断**：
   - 基于 Python `ctypes` 动态加载 `CAENComm.dll` 与 `DT5800_SDK.dll`；
   - 编写连接管理类 `DT5800Controller`，实现设备自动扫描、打开句柄、通道配置（Channel 1: Det-1, Channel 2: Det-2）；
   - 编写诊断工具验证当前固件对 AWG 模式和 Emulation 模式的支持状态。
2. **AWG 模式推流与播放控制器**：
   - 将模块二生成的 1 MSamples 格式化波形通过 SDK 批量写入 DT5800 板载 RAM；
   - 配置时钟分频系数（设定 DAC 采样率，如 250 MS/s 或 50 MS/s）；
   - 触发播放：支持“软件单次触发（单脉冲/瞬态回放）”与“内部连续循环触发（稳态模拟）”。
3. **Emulation 动态流式参数推送（双轨保障）**：
   - 将 He-3 实验能谱与脉冲形状写入 DT5800 固化配置；
   - 建立高频异步工作线程，当 UI 棒位变动导致 $\lambda(t)$ 变化时，以 $20\sim 50\text{ Hz}$ 速率向硬件更新到达率寄存器，物理 BNC 接口即刻输出密度渐变的连续模拟脉冲流。

### 3.4 模块四实施方案（可选优化项）：物理实验信号比对与孪生优化
1. **实测波形数据接入**：
   - 复用前期 `code_doc/docs/EXPERIMENT_DATA_COLLECTION.md` 规范，导入示波器采集的真实 He-3 正比计数管前放波形；
2. **探测器关键物理参数反向标定**：
   - 从实测孤立脉冲中拟合提取真实上升时间 $\tau_r$（如 $0.15\ \mu\text{s}$）与衰减时间 $\tau_d$（如 $2.4\ \mu\text{s}$）；
   - 提取真实电子学噪声功率谱密度（PSD）底噪与死时间常数；
   - 将标定参数回填到模块二的信号生成内核与 DT5800 形状文件中，消除仿真与实验之间的系统性偏差。
3. **端到端闭环反演验证**：
   - 采集 DT5800 物理输出信号，重新运行 `he3sim.analysis`（Rossi-$\alpha$ / Feynman-$\alpha$）；
   - 检验反演得到的衰减常数 $\alpha$ 与模块一设定的真值偏差，要求相对误差 $\le 5\%$。
